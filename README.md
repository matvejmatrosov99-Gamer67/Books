# Читательский круг — книжный клуб

Адаптивный сайт книжного клуба на HTML, CSS и JavaScript.

## Возможности
- Каталог книг, поиск и фильтр
- Добавление книг и оценки от 1 до 5
- Список чтения с сохранением в localStorage
- Обсуждения и публикация новых тем
- Встречи, календарь и управление событиями
- Участники и редактируемый профиль
- Адаптация для компьютеров и телефонов

## Запуск
Откройте `index.html` в браузере.

## GitHub Pages
В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**. После публикации сайт будет доступен по адресу `https://matvejmatrosov99-gamer67.github.io/Books/`.

Данные демоверсии сохраняются в localStorage браузера. Для общей базы данных понадобится серверная часть и БД.
